1. Novo tipo de rolê
	•	Adicionar “Viagem em Grupo” como opção no seletor de tipo de evento.
	•	Chave a ser usada: "tipoRole": "viagem_grupo"

⸻

2. Sugestão de destinos + votação (opcional)
	•	Adicionar opção:
“Deseja sugerir locais para votação?” → boolean (true / false)
	•	Se true: permitir inserir até 3 sugestões de destinos com valor estimado:

"sugestoesViagem": [
  { "local": "Praia do Rosa", "valorEstimado": 500 },
  { "local": "Campos do Jordão", "valorEstimado": 650 },
  { "local": "Capitólio", "valorEstimado": 550 }
]

	•	Participantes poderão votar em 1 dos 3 destinos
	•	Mostrar votos acumulados para cada opção
	•	Definir local escolhido com base na maioria

⸻

3. Confirmação de presença
	•	Participantes devem confirmar se vão:
Botão: "Vai nessa viagem?" → adiciona nome à lista confirmados

"confirmados": ["João", "Lia", "Carlos"]


⸻

4. Campo de custo estimado por pessoa (opcional)
	•	Inserido pelo organizador:

"custoPorPessoa": 550


⸻

5. Checklist de itens compartilhados (como em festas)
	•	Lista com campos de nome do item e responsável (editável)

"itensCompartilhados": [
  { "nome": "Caixa de som", "responsavel": "João" },
  { "nome": "Cooler", "responsavel": "" }
]


⸻

6. Campo opcional: link do destino (Google Maps ou site)

"linkDestino": "https://maps.google.com/?q=Campos+do+Jordão"
